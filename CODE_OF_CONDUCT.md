# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, without modification.

The full text is published at:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Plain text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt>

It applies to every space this project uses — issues, pull requests, discussions and any other channel — and to anyone representing the project in public spaces.

## Reporting

Instances of abusive, harassing or otherwise unacceptable behaviour may be reported to the project maintainers.

> **Maintainers:** replace this paragraph with the contact you want reports sent to — a private email address, or GitHub's [private vulnerability and abuse reporting](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). No contact address is invented here, because a code of conduct with an address nobody reads is worse than none.

All complaints will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of the reporter of any incident.

Maintainers who do not follow or enforce this Code of Conduct in good faith may face temporary or permanent repercussions as determined by other members of the project's leadership.

## Enforcement guidelines

Consequences follow the four-step ladder defined in Contributor Covenant 2.1 — correction, warning, temporary ban, permanent ban — as described in the linked text.
